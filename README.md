# Chat App CSS Illustration

A responsive chat interface illustration built with pure HTML and CSS, with no images except the avatar and photos.

This is my solution to the [Frontend Mentor](https://www.frontendmentor.io) challenge "Chat app CSS illustration".

## Live Demo and Code

- **Live site:** https://faheenafaheen.github.io/Chat-app-CSS-illustration/
- **Repository:** https://github.com/faheenafaheen/Chat-app-CSS-illustration

## The challenge

Users should be able to:

- View the best layout for the component on different screen sizes
- (Bonus) See the chat interface animate on the first load

## Built with

- Semantic HTML5
- CSS custom properties
- Flexbox
- Mobile-first responsive layout

## What I practised

- Building UI shapes such as chat bubbles using only CSS
- Layout and spacing with Flexbox
- Matching a design closely with limited assets

## Run it locally

```bash
git clone https://github.com/faheenafaheen/Chat-app-CSS-illustration.git
cd Chat-app-CSS-illustration
```

Open `index.html` in your browser. No build step is needed.
